# 📊 Employee Data Analysis with Python

A data analysis project demonstrating statistical insights and visualizations using **Pandas**, **Matplotlib**, and **Seaborn**.

## 📝 Overview
This project analyzes synthetic employee data to explore trends in:
*   Salary distribution across departments.
*   Gender diversity ratios.
*   Age demographics.
*   Correlation between age and salary.

*Note: The dataset used is simulated via a Python dictionary for demonstration purposes.*

## 🛠️ Tools & Libraries
*   **Language**: Python
*   **Libraries**: Pandas, Matplotlib, Seaborn
*   **Environment**: Jupyter Notebook

## 📈 Visualizations Included
1.  **Bar Chart**: Average Salary by Department.
2.  **Pie Chart**: Gender Distribution (%).
3.  **Box Plot**: Salary Spread & Outliers by Gender.
4.  **Histogram**: Age Distribution with KDE curve.
5.  **Scatter Plot**: Age vs. Salary (colored by Department).

## 🚀 How to Run
1.  Clone this repository.
2.  Ensure you have the required libraries:
    ```bash
    pip install pandas matplotlib seaborn
    ```
3.  Open **`Company.ipynb`** in Jupyter Notebook or VS Code.
4.  Run all cells to generate the visualizations.
